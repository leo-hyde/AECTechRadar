# AEC Tech Radar

A research map of technology firms in construction, engineering and
architecture (AEC for short). It's built to help advise firms that want to
move from *using some AI* to *putting AI at the centre of how they work*.
Every fact links to where it came from.

**Site:** https://leo-hyde.github.io/AECTechRadar/

> Early prototype. An AI assistant researched the entries, and a person hasn't
> checked them yet. Check the sources before relying on anything here.

## For people
Browse the site. It has a map of categories, a list of companies you can
filter, every source we cite, and other people's analysis of the same field.

## For AI tools
These files are plain text, so AI tools can read them directly:
- [`llms.txt`](llms.txt): an index of everything, in a standard format for AI
  tools (see llmstxt.org)
- [`data/radar.json`](data/radar.json): all the data in one file
- `companies/`, `categories/`, `analyses/`: one Markdown (plain text) file per
  entry, with its key facts listed at the top
- [`docs/METHOD.md`](docs/METHOD.md): how we do the research and what each
  field means

## Spotted a mistake?
