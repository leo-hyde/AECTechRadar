# AEC Tech Radar

A research map of construction, engineering and architecture (AEC)
technology firms, built to help advise firms moving from *using some AI* to
*putting AI at the centre of how they work*. Every fact links to its source.

**Site:** https://leo-hyde.github.io/aec-tech-radar/

> Early prototype. Entries are AI-researched drafts, not yet checked by a
> person. Check the sources before relying on anything here.

## For people
Browse the site: a map of categories, a filterable company list, every source
cited, and other people's analysis of the same landscape.

## For AI tools
- [`llms.txt`](llms.txt): an index of everything (see llmstxt.org)
- [`data/radar.json`](data/radar.json): all the data in one file
- `companies/`, `categories/`, `analyses/`: one Markdown file per entry, with
  structured facts at the top
- [`docs/METHOD.md`](docs/METHOD.md): how the research is done and what each
  field means

## Contributing a correction
Each page has a "Correct it on GitHub" button. Please include a source.
